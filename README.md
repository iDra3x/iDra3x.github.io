# iDra3x — bilingual technical portfolio

A static, responsive Arabic/English portfolio for Alayham Al-asmi. The homepage is at the repository root so GitHub Pages can serve it directly. The former DIRX Studio page remains at `DIRX-Studio/index.html`.

## Files

```text
index.html                 Page structure and default Arabic copy
assets/css/style.css       Layout, colors, mobile styles, accessibility
assets/js/main.js          Arabic/English copy and language switch
DIRX-Studio/               Archived studio page and assets
README.md                  Project notes
```

## Sections

About · Skills · MTA projects · HTML/CSS, Lua/MTA, JavaScript services · Contact.

The MTA cards describe projects/concepts without claiming published demos. Add verified screenshots and project URLs when available. Contact links point to GitHub and @devorbit.om; verify that the Instagram account is the preferred public contact before merging.

## Preview

Open `index.html` locally in a browser. No build tools or dependencies are required. Use the AR/EN switch, check the layout on desktop and mobile, and confirm both contact links. For GitHub Pages, deploy from the `main` branch root after merging this PR.
